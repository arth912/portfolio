# 🚀 Quick Start Guide

Get your portfolio running in 5 minutes!

## Prerequisites
- Node.js (v16+)
- npm or yarn

## Installation

```bash
# 1. Navigate to project folder
cd arth-rathod-portfolio

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

Open your browser: **http://localhost:3000**

## 📝 Customize Your Portfolio

### Update Personal Information

1. **Contact Info** - Edit `src/components/Contact.jsx`
2. **Hero Section** - Edit `src/components/Hero.jsx`
3. **About** - Edit `src/components/About.jsx`
4. **Skills** - Edit `src/components/Skills.jsx`
5. **Experience** - Edit `src/components/Experience.jsx`
6. **Projects** - Edit `src/components/Projects.jsx`
7. **Education** - Edit `src/components/Education.jsx`
8. **Certifications** - Edit `src/components/Certifications.jsx`

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## 🌐 Deploy

### Deploy to Netlify (Easiest)

1. Push to GitHub
2. Go to [netlify.com](https://netlify.com)
3. Click "New site from Git"
4. Connect repository
5. Click "Deploy"

**Done!** Your site is live in minutes.

See `DEPLOYMENT_GUIDE.md` for detailed deployment options.
