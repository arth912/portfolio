## 🚀 How to Use

### 1. Development Mode
```bash
npm install
npm run dev
```
Visit: http://localhost:3000

### 2. Build for Production
```bash
npm run build
```
Output: `dist/` folder

### 3. Preview Production Build
```bash
npm run preview
```

### 4. Deploy to Netlify (Recommended)
```bash
# Option 1: Via Dashboard
1. Push to GitHub
2. Connect on netlify.com
3. Deploy automatically

# Option 2: Via CLI
npm install -g netlify-cli
netlify login
netlify deploy --prod
```

## 📝 Customization Guide

### Update Personal Information

1. **Contact Details** → `src/components/Contact.jsx` (lines 8-32)
2. **Hero Section** → `src/components/Hero.jsx` (lines 31-55)
3. **Social Links** → Multiple files (search for URLs)
4. **Resume Content** → `src/components/Hero.jsx` (handleDownloadResume function)

### Update Content

1. **About Text** → `src/components/About.jsx`
2. **Skills List** → `src/components/Skills.jsx` (lines 4-30)
3. **Experience** → `src/components/Experience.jsx` (lines 5-50)
4. **Projects** → `src/components/Projects.jsx` (lines 6-75)
5. **Education** → `src/components/Education.jsx` (lines 5-12)
6. **Certifications** → `src/components/Certifications.jsx` (lines 5-38)

### Change Colors

Edit `tailwind.config.js`:
```javascript
colors: {
  primary: {
    500: '#3b82f6',  // Change this
    600: '#2563eb',  // And this
    // ... etc
  }
}
```
